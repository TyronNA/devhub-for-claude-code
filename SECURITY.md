# Security

Dev Hub runs coding agents on your machine. The optional phone web app (`devHub.mobile.enabled`)
listens on your local network, and its passcode is the only thing guarding it, so a bypass there
is serious.

**Please do not open a public issue for a vulnerability.** Report it privately through
[GitHub security advisories](https://github.com/TyronNA/devhub-for-claude-code/security/advisories/new).
Include the Dev Hub version, the steps to reproduce, and what an attacker gains.

Only the latest release is supported.
